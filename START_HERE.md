# НАЧНИТЕ ЗДЕСЬ!

## Добро пожаловать в игру "Ассоциации"!

Это словесная игра, где нужно угадать слово по набору ассоциаций из русского ассоциативного словаря.

---

## 🚀 Быстрый запуск (3 шага)

### Шаг 1: Проверьте Python
```bash
python --version
```
Должна быть версия 3.7 или выше

### Шаг 2: Откройте терминал в папке проекта
```bash
cd c:\GitHub\Associations
```

### Шаг 3: Запустите игру!
```bash
python main.py
```

## ❓ Частые вопросы

**Q: Игра не запускается**
A: Проверьте версию Python (должна быть 3.7+) командой `python --version`

**Q: Словарь не загружается**
A: Убедитесь, что файл словаря находится в той же папке, что и main.py

**Q: Где сохраняются результаты?**
A: В файле `player_stats.json` в папке с игрой

**Q: Можно ли играть вдвоем?**
A: Да! Создайте два профиля игроков и соревнуйтесь в таблице лидеров

**Q: Как удалить статистику?**
A: Удалите файл `player_stats.json`
