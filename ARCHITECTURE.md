# Архитектура игры "Ассоциации"

## Обзор

Игра разделена на несколько модулей, каждый из которых отвечает за свою функциональность.

## Структура модулей

### 1. dictionary_parser.py
**Назначение:** Парсинг ассоциативного словаря

**Классы:**
- `DictionaryParser` - основной класс для работы со словарем

**Ключевые методы:**
- `parse()` - парсит файл словаря и возвращает словарь формата `{слово: [(ассоциация, частота), ...]}`
- `get_words()` - возвращает список всех слов
- `get_associations(word)` - возвращает ассоциации для конкретного слова
- `_parse_entry(line)` - парсит одну словарную статью
- `_parse_associations(text)` - парсит строку с ассоциациями

**Формат данных:**
```python
{
    'АВТОМАТ': [
        ('Калашникова', 152),
        ('оружие', 58),
        ('Калашников', 27),
        ...
    ],
    ...
}
```

### 2. game_logic.py
**Назначение:** Основная игровая логика

**Классы:**
- `Difficulty(Enum)` - перечисление уровней сложности
- `GameConfig` - конфигурация для каждого уровня
- `AssociationsGame` - основной класс игры

**Ключевые методы:**
- `start_new_round(difficulty)` - начинает новый раунд
- `reveal_next_association()` - открывает следующую ассоциацию
- `make_guess(guess)` - обрабатывает попытку угадывания
- `get_hint()` - предоставляет подсказку
- `_calculate_score()` - рассчитывает очки за правильный ответ
- `_get_suitable_words(config)` - выбирает подходящие слова для уровня

**Алгоритм выбора слов:**
1. Фильтрация слов по минимальной частоте ассоциаций
2. Проверка наличия достаточного количества ассоциаций
3. Случайный выбор слова из подходящих

**Система очков:**
```
Базовые очки = (оставшиеся попытки, включая текущую) × (множитель сложности) × 100
Бонус за первую попытку = +500
Штраф за подсказку = -100 за каждую
```

### 3. player_stats.py
**Назначение:** Персистенция результатов игроков

**Классы:**
- `PlayerStats` - управление статистикой игроков

**Ключевые методы:**
- `add_player(name)` - добавляет нового игрока
- `record_game(...)` - записывает результат игры
- `get_player_stats(name)` - получает статистику игрока
- `get_leaderboard(limit)` - формирует таблицу лидеров
- `get_player_history(name, limit)` - получает историю игр
- `export_stats(filename)` - экспортирует статистику
- `import_stats(filename)` - импортирует статистику

**Формат хранения (JSON):**
```json
{
  "players": {
    "Иван": {
      "total_score": 3500,
      "games_played": 10,
      "games_won": 7,
      "games_lost": 3,
      "best_score": 1500,
      "difficulty_stats": {
        "EASY": {"played": 3, "won": 3},
        "MEDIUM": {"played": 4, "won": 3},
        ...
      },
      "history": [
        {
          "date": "2025-01-15T10:30:00",
          "difficulty": "EASY",
          "won": true,
          "score": 800,
          "word": "АВТОМАТ"
        },
        ...
      ]
    }
  }
}
```

### 4. main.py
**Назначение:** Пользовательский интерфейс

**Классы:**
- `AssociationsGameUI` - консольный интерфейс игры

**Ключевые методы:**
- `run()` - запуск игры
- `load_dictionary()` - загрузка словаря
- `select_player()` - выбор/создание игрока
- `select_difficulty()` - выбор уровня сложности
- `play_round(difficulty)` - игра одного раунда
- `show_stats()` - отображение статистики
- `show_leaderboard()` - отображение таблицы лидеров
- `main_menu()` - главное меню

**Игровой цикл:**
```
Запуск
  ↓
Загрузка словаря
  ↓
Выбор/создание игрока
  ↓
Главное меню ←─────┐
  ↓                 │
Выбор сложности    │
  ↓                 │
Игровой раунд      │
  ↓                 │
Сохранение результатов
  ↓                 │
Возврат в меню ────┘
```

## Поток данных

```
Словарь (txt)
    ↓
DictionaryParser.parse()
    ↓
Словарь (dict) → AssociationsGame
    ↓                   ↓
    │              Игровая логика
    │                   ↓
    │              Результат игры
    │                   ↓
    └──────────→ PlayerStats.record_game()
                        ↓
                   JSON файл
```

## Расширяемость

### Добавление новых уровней сложности
Добавьте новый уровень в `Difficulty` enum и соответствующую конфигурацию в `GameConfig.CONFIGS`.

### Добавление новых источников словарей
Создайте новый парсер, наследующий базовую логику `DictionaryParser`, или адаптируйте метод `parse()`.

### Добавление графического интерфейса
Замените `AssociationsGameUI` на графический интерфейс (tkinter, PyQt, pygame), сохранив логику из `game_logic.py` и `player_stats.py`.

### Многопользовательский режим
Расширьте `PlayerStats` для поддержки одновременных сессий и добавьте сетевую логику.

## Зависимости

Проект использует только стандартную библиотеку Python 3.7+:
- `json` - для работы с JSON
- `os` - для файловых операций
- `sys` - для управления программой
- `re` - для регулярных выражений в парсере
- `random` - для выбора случайных слов
- `datetime` - для временных меток
- `enum` - для перечислений

## Производительность

- Загрузка словаря: ~1-2 секунды (1000+ слов)
- Запуск раунда: мгновенно
- Сохранение статистики: мгновенно
- Память: ~10-20 MB (в зависимости от размера словаря)

## Обработка ошибок

- Отсутствие файла словаря: выход с сообщением об ошибке
- Ошибки парсинга: пропуск проблемных строк
- Ошибки записи статистики: вывод сообщения, продолжение работы
- Некорректный ввод: повторный запрос

## Безопасность

- Данные игроков хранятся локально
- Нет сетевых запросов
- Нет выполнения произвольного кода
- Безопасная обработка пользовательского ввода
