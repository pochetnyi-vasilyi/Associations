# Быстрый старт - Игра "Ассоциации"

## Установка и запуск

1. Убедитесь, что у вас установлен Python 3.10 или выше:
   ```bash
   python --version
   ```

2. Перейдите в директорию игры:
   ```bash
   cd c:\GitHub\Associations
   ```

3. Запустите игру:
   ```bash
   python main.py
   ```

## Первые шаги

1. При первом запуске введите свое имя для создания профиля игрока
2. Выберите уровень сложности (рекомендуем начать с "Легкого")
3. Читайте ассоциации и пытайтесь угадать загаданное слово
4. Используйте подсказки, если застряли (но это уменьшит ваш счет!)

## Пример игры

```
============================================================
           ИГРА 'АССОЦИАЦИИ'
============================================================

Игрок: Иван
Уровень: EASY
Попыток осталось: 5

Ассоциации:
  1. машина (частота: 13)
  2. оружие (частота: 58)
  3. Калашникова (частота: 152)

Что делать?
1. Попытаться угадать слово
2. Открыть следующую ассоциацию
3. Взять подсказку (-100 очков)
4. Сдаться

> 1

Ваш ответ: автомат

*** ПРАВИЛЬНО! ***

Слово было: АВТОМАТ
Вы получили 1000 очков!
```

## Советы

- На легком уровне показываются самые частые ассоциации
- На сложных уровнях могут быть редкие и необычные ассоциации
- Бонус +500 очков за угадывание с первой попытки!
- Используйте подсказки только в крайнем случае
- Смотрите таблицу лидеров для мотивации

## Дополнительные возможности

- Просмотр личной статистики (меню "Моя статистика")
- Таблица лидеров с топ-10 игроков
- История последних 100 игр
- Возможность смены игрока без перезапуска

## Тестирование

Для проверки работоспособности всех компонентов:
```bash
python test_game.py
```

## Помощь

Если возникли проблемы, проверьте:
- Версию Python (должна быть 3.10+)
- Наличие файла словаря в той же директории
- Права на запись (для сохранения статистики)

Приятной игры!
