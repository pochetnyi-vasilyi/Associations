# Сводка проекта "Ассоциации"

## Выполненные требования

### ✓ Основная механика игры
- [x] Угадывание слова по ассоциациям из словаря
- [x] Постепенное открытие ассоциаций
- [x] Ограниченное количество попыток
- [x] Система подсказок

### ✓ Уровни сложности
- [x] **Легкий** - 5 частых ассоциаций, 5 попыток, множитель x1
- [x] **Средний** - 4 ассоциации, 4 попытки, множитель x2
- [x] **Сложный** - 3 ассоциации (включая редкие), 3 попытки, множитель x3
- [x] **Эксперт** - 2 редкие ассоциации, 2 попытки, множитель x5

### ✓ Система очков
- [x] Базовый расчет: попытки × сложность × 100
- [x] Бонус за первую попытку: +500
- [x] Штраф за подсказки: -100 за каждую

### ✓ Персистенция данных
- [x] Сохранение статистики в JSON файл
- [x] История последних 100 игр
- [x] Статистика по уровням сложности
- [x] Таблица лидеров
- [x] Импорт/экспорт статистики

### ✓ Пользовательский интерфейс
- [x] Консольный интерфейс
- [x] Главное меню с опциями
- [x] Выбор/создание игрока
- [x] Просмотр статистики
- [x] Таблица лидеров

## Особенности реализации

1. **Умный парсер** - обрабатывает многострочные словарные статьи
2. **Адаптивная сложность** - выбор слов с учетом частоты ассоциаций
3. **Постепенное раскрытие** - от редких к частым ассоциациям
4. **Надежная персистенция** - обработка ошибок записи
5. **Гибкая конфигурация** - легко менять параметры уровней
