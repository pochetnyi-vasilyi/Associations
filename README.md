# Игра "Ассоциации"

Словесная игра, где нужно угадать слово по набору ассоциаций из русского регионального ассоциативного словаря-тезауруса ЕВРАС.

## Описание

Игрок получает несколько ассоциаций к загаданному слову и должен угадать его за ограниченное количество попыток. Ассоциации показываются постепенно - от редких к более частым.

## Уровни сложности

### 1. Легкий
- 5 самых частых ассоциаций
- 5 попыток на угадывание
- Множитель очков: x1

### 2. Средний
- 4 ассоциации (включая менее частые)
- 4 попытки на угадывание
- Множитель очков: x2

### 3. Сложный
- 3 ассоциации (включая редкие)
- 3 попытки на угадывание
- Множитель очков: x3

### 4. Эксперт
- 2 редкие ассоциации
- 2 попытки на угадывание
- Множитель очков: x5

## Система очков

**Расчет очков за правильный ответ:**
```
Базовые очки = (оставшиеся попытки, включая текущую) × (множитель сложности) × 100
```

**Бонусы и штрафы:**
- Бонус за угадывание с первой попытки: +500 очков
- Штраф за каждую использованную подсказку: -100 очков

**Примеры:**
- Легкий уровень, угадано со 2-й попытки (осталось 4 попытки): 4 × 1 × 100 = 400 очков
- Средний уровень, угадано с 1-й попытки (осталось 4 попытки): 4 × 2 × 100 + 500 = 1300 очков
- Эксперт, угадано с 1-й попытки (осталось 2 попытки): 2 × 5 × 100 + 500 = 1500 очков

## Требования

- Python 3.7 или выше
- Стандартная библиотека Python (не требуется установка дополнительных пакетов)

## Как играть

1. Запустите игру командой `python main.py`
2. Выберите существующего игрока или создайте нового
3. Выберите уровень сложности
4. Постепенно открывайте ассоциации и пытайтесь угадать слово
5. Используйте подсказки при необходимости (штраф -100 очков)
6. Просматривайте свою статистику и таблицу лидеров

## Меню игры

**Главное меню:**
- Играть - начать новую игру
- Моя статистика - просмотр личной статистики
- Таблица лидеров - топ-10 игроков
- Сменить игрока - выбрать другого игрока
- Экспорт статистики - сохранить статистику всех игроков в файл
- Импорт статистики - добавить игроков из файла (существующие не перезаписываются, записи с ошибками пропускаются с объяснением причины)
- Выход - завершить игру

**Во время игры:**
- Попытаться угадать слово
- Открыть следующую ассоциацию
- Взять подсказку (показывает первые буквы слова)
- Сдаться

## Статистика

Для каждого игрока сохраняется:
- Общий счёт
- Количество сыгранных игр
- Количество побед и поражений
- Лучший результат
- Процент побед
- Статистика по уровням сложности
- История последних 100 игр

## Формат словаря

Словарь использует формат:
```
СЛОВО: ассоциация1 частота1; ассоциация2, ассоциация3 частота2; ...
```

Где:
- СЛОВО - заголовочное слово
- ассоциация - слово или фраза, ассоциированное со стимулом
- частота - число, указывающее на частоту появления ассоциации
